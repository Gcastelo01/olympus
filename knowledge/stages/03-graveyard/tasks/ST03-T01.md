2. Resolve stable record introduction from reachable history, require an unambiguous usable parent and verify every old/new path/blob descriptor. Report pending uncommitted records separately from verified BURIED events.
3. Implement bounded read-only exhume and exclusive --export under .olympus/exhumed with safe receipts. EXHUMED is local inspection; RESTORED requires separately reviewed reintegration evidence, never export alone.
4. Build temp histories with record+retirement in the same commit, rename, partial-symbol file change, linked multi-commit events, squashed/rewritten/cherry-picked history, root/ambiguous introduction, shallow/missing objects and malformed record fixtures.

## Acceptance criteria

- [ ] Removal commit and original whole-file blobs resolve only if before/after descriptors match. No embedded self-referential SHA or unverified semantic-symbol proof.
- [ ] Accessible rewritten histories work when descriptors still match; otherwise TRACE_UNAVAILABLE with reason, no automatic fetch or recovery promise.
- [ ] Exhume default modifies no application files; exports reject collisions, links and escaped paths, enforce byte limits and clean only invocation-owned partial output.
- [ ] Invalid/incomplete records fail clearly; uncommitted entries cannot claim BURIED; no command overwrites application or prior exports.
- [ ] Literal Git paths block pathspec/argument injection and lifecycle never equates EXHUMED with RESTORED.
