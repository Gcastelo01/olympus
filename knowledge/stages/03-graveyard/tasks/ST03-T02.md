## Goal and current evidence

Athena explicit Hermes/Hades artifact boundary; missing and changed paths may match logical or partial retirements.

## Scope and invariants

src/context and src/graveyard explicit interface plus integration fixtures. No tight coupling to Hades execution or memory service.

## Implementation steps

1. Query bounded validated graveyard metadata for missing/divergent checkpoint references by old path, including partial-symbol retirements.
2. Attach matching ID, reason, successor and trace status to reconciliation findings. Handle absent graveyard and invalid/unavailable history honestly.
3. Exercise a checkpoint before retirement and load it after an actual record+removal commit; also cover modified file/partial removal, unrelated entries and malicious records.

## Acceptance criteria

- [ ] Retirement explanation improves reconciliation but never makes changed evidence current or suppresses reconciliation.
- [ ] Unknown/invalid graveyard metadata cannot cause application writes, shell execution or automatic recovery.
- [ ] Projects with no graveyard retain functional portable checkpoint loading; unchanged artifacts remain ready when all other checks match.
