### Ordered implementation additions

1. Extend immutable schema v1 with `taskStatus` (`active`, `paused`, `completed`) and optional `supersedes` containing predecessor ID and digest. Successors must retain task/project/branch lineage; preserve original review/test provenance rather than assigning a fresh fingerprint to old evidence. Use the accepted contract for validation, not an active pointer or timestamp ranking.
2. Implement read-only `olympus context discover [--task <task-id>] [--json]`, using the same project targeting option as other context operations. Scan only immediate regular managed JSON files under the selected project's `.olympus/context/`, with explicit count/byte limits, conservative names and safe metadata display. Never search home, sibling projects, remote memory or repository contents recursively.
3. Establish relevance from project, current branch and an explicit unambiguous task selector. Validate predecessor digest, task/project/branch agreement and acyclic lineage; a completed leaf excludes its predecessors, and paused tasks remain available. Exactly one unfinished head yields SELECTED; no relevant task yields NONE; missing lineage, conflicting heads/tasks, ambiguous project/branch or invalid data preventing selection yields SELECTION_REQUIRED. An explicitly named missing/invalid checkpoint is an error. Never pick newest timestamp or an older checkpoint because it passes load.
4. Keep discovery and load separate: selection never certifies evidence. Re-observe state in load, including changes since discovery, and require reconciliation where appropriate. Discovery emits only bounded IDs/task status/runtime/branch/timestamp/chain/issues, excluding objectives, authorization notes and free text before selection. Scan limits cannot produce partial-success selection.
5. Make prune explain that deleting predecessors can make future lineage incomplete. Surface failed saves and the last successfully persisted checkpoint; never overwrite predecessor or concurrent successors. Keep context NONE read-only and successful without creating directories.
