## Implementation steps

1. Implement only shared primitives required by the accepted context/graveyard contracts: strict bounded JSON and IDs, portable relative paths, real containment and symlink-ancestor rejection, exclusive restrictive writes and invocation-owned failure cleanup.
2. Use fixed-argument bounded/time-limited read-only Git subprocesses with literal paths, optional locking disabled and no hooks/shell/external conversion. Derive sanitized portable project identity and full content-aware work/index/reference fingerprints.
3. Implement conventional sensitive-path rejection and recognizable secret/private-key rejection without echoing values; limit referenced sizes/counts and never inspect arbitrary environment or secret files. Exclude only named transient directories, not all .olympus.
4. Create meaningful temp-repository tests and record Node/Git/platform versions. Keep implementations standard-library only.

## Acceptance criteria

- [ ] Path traversal, absolute/drive/UNC/backslash/control paths, symlink ancestors, malformed/oversized JSON and exclusive-create collisions fail safely without application writes.

- [ ] Credentials in remote identities are not persisted; rejected secrets never appear in errors. Timeout/output-limit and Git failure produce clear failures, never silent success.
- [ ] Existing install/check interfaces remain compatible; no production dependency or lockfile change.
